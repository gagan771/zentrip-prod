# Golden Triangle operational research

Captured 2026-08-28 using direct web search. Firecrawl was not used.

The API stores these as short, reviewable observations rather than copied page
bodies. Hours and ticket links refresh after 30 days; café ratings refresh after
7 days. The Humayun's Tomb disagreement is deliberately retained as a
`needs_review` observation instead of silently choosing one source.
